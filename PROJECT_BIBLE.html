I

Project Overview & Vision

This project is a self-contained, browser-based cinematic curriculum for learning the entire history of human civilization through film, television series, miniseries, and documentaries. It consists of a central hub file (the master empires tree) and a set of individual empire timeline files — one per empire — each showing the complete watch order from that empire's founding to its fall.

The project was conceived because no streaming guide, Wikipedia article, or YouTube video adequately answers the question: "If I wanted to learn the entire history of Rome — or Egypt, or the Ottomans — through only film and television, in the right order, what would I watch?" This system answers that question definitively for every major civilization with adequate screen coverage.

The Two-Level Structure

Level 1 — The Hub: A single HTML file (index.html) displaying all empires as a visual tree. Each empire node is a clickable card that navigates to that empire's dedicated timeline file. The hub shows empire names, date ranges, and their relationship to one another (main succession trunk, fork/successor, or concurrent).

Level 2 — Empire Files: One HTML file per empire (e.g., rome.html, egypt.html, etc.). Each file is a complete, self-contained cinematic timeline — a vertical alternating tree of phases, each phase containing the films and series that cover that historical period, with character spotlights, watch-order notes, and parallel viewing instructions.

The Aesthetic Contract

All files share the same foundational aesthetic: a dark marble background, serif typography using the Cinzel (headings) and Cormorant Garamond (body) font pairing, a gold-and-crimson color language, and the same alternating left-right tree layout. What varies between empire files is a single accent color ramp that replaces the Roman crimson — so the Egyptian file has a turquoise-and-sand palette, the Persian file has an amethyst-and-gold palette, and so on. The marble stays. The fonts stay. The layout stays. Only the accent shifts. This makes the collection feel unified while giving each empire its own identity.

Core Principle: Every file in this project must feel like it belongs to the same hand-crafted historical atlas. A person who opens mongol.html after reading rome.html should immediately recognize the family, but feel the shift in culture through the changed palette.

Linking Rules — Hub → Empire

Every empire node on the hub tree contains a clickable link. When clicked, it opens that empire's individual HTML file. The link is implemented as a standard <a href="rome.html"> wrapped around the empire's node card on the hub. The node must visually indicate it is clickable — a subtle gold border glow on hover is the correct treatment. There is no JavaScript required for basic navigation; all links are standard anchor tags.

Linking Rules — Empire → Hub

Every individual empire file must have a "Return to All Empires" link in the header, placed below the title. It reads: ← All Empires and links back to index.html. It uses the .back-link CSS class defined in the boilerplate. It is styled as a small Cinzel-font label in muted gold, with a left-pointing arrow character (←). It appears on one line, centered, between the ornament and the main H1 title.

Self-Contained Files

Critical Rule: Every file — hub and empire files alike — must be 100% self-contained. All CSS is embedded in a <style> block in the <head>. No external stylesheets. No JavaScript frameworks. The only external resources are the two Google Fonts imports (Cinzel and Cormorant Garamond). The files must work when opened directly from a file system without a server.

This exact import line must appear in every file, unchanged:

III

Build Order — What to Make First

Build in this exact sequence. Do not skip ahead. Each stage depends on the clarity established by the previous one.

  1. Complete rome.html — This file already exists and serves as the master reference. Every other empire file is built to match its structure exactly. If anything feels wrong in a later file, refer back to rome.html and copy the pattern precisely.
  2. Build index.html (the Hub) — Before building any more empire files, build the hub. The hub's visual grammar (amber trunk = main succession, purple solid = fork/successor, teal dashed = concurrent) must be established before it can be populated. The hub is the "map" that will guide the user. Build it with placeholder links for all empires not yet built (grayed-out nodes with "Coming Soon" treatment).
  3. Build ottoman.html — The Ottoman Empire has the richest modern media coverage outside Rome (Rise of Empires, Magnificent Century, etc.) and is the direct chronological successor to Byzantium/Rome on the main trunk. Build this third to validate that the Rome template scales cleanly to a different culture and color palette.
  4. Build egypt.html — Massive film coverage (Cleopatra, The Ten Commandments, Pharaoh, Nefertiti, etc.), historically early, and visually distinct palette. Good stress test for the template.
  5. Build mongol.html — Tests the Eastern/non-Western media challenge. Forces you to include Chinese and Mongolian productions alongside Western content.
  6. Build british.html — The deepest media coverage of any modern empire. Will likely be the longest file. Covers ~1583–1997 AD and spans dozens of phases.
  7. Build all remaining empire files in rough chronological order: persia.html, macedon.html, maurya.html, han.html, viking.html, islamic.html, spanish.html, mughal.html, russian.html, napoleon.html, japanese.html.
  8. Final pass — update index.html — Once all empire files are complete, revisit the hub and replace all "Coming Soon" placeholder nodes with fully linked, active nodes. Verify all links work. Add any new relationships discovered during the empire builds.

The Marble Background

The background is not a flat color. It uses a body::before pseudo-element with two layered repeating-linear-gradients at 105° and 75° to create a subtle marble vein texture. The gradients use rgba(255,255,255,0.008) and rgba(255,255,255,0.005) — extremely faint, almost invisible. The background color itself is #0e0c0a — a very dark warm brown-black, not pure black. This warmth is critical; pure black (#000000) makes the file feel sterile rather than historical.

Marble Texture (body::before)
body::before {
  content: '';
  position: fixed;
  inset: 0;
  background-image:
    repeating-linear-gradient(
      105deg,
      transparent, transparent 40px,
      rgba(255,255,255,0.008) 40px,
      rgba(255,255,255,0.008) 41px
    ),
    repeating-linear-gradient(
      75deg,
      transparent, transparent 60px,
      rgba(255,255,255,0.005) 60px,
      rgba(255,255,255,0.005) 61px
    );
  pointer-events: none;
  z-index: 0;
}

The Central Trunk Line

The vertical timeline line running down the center of every empire file is produced by a single div.trunk positioned absolutely within the div.tree container. It is 2px wide, centered at 50%, and uses a vertical linear gradient that fades from solid gold at the top to transparent at the bottom (at 85–90% of its height). Opacity of the trunk itself is set to 0.45–0.5. The gold trunk color is always #c9a84c — the empire accent color does NOT affect the trunk.

VI

The Hub File — Main Empires Tree (index.html)

The hub is a single-page HTML file using the same marble-dark aesthetic as the empire files. It displays all empires as a visual chronological tree, organized into three visual lanes:

Three-Lane Structure

Lane 1 (Center-Left, amber nodes): The main succession trunk. These are empires that directly conquered, replaced, or inherited the previous one's dominant world-region. The main Western trunk runs: Egypt → Persia → Rome → Byzantine → Ottoman. The main Eastern trunk runs: Maurya → Han → Mongol → Mughal. These are amber-colored nodes connected by a vertical gold line.

Lane 2 (Right, purple nodes, solid connector): Forks and successor states. Empires that split off from, claimed succession to, or emerged directly from a trunk empire. Examples: Macedonian (forked from the Persian world), Holy Roman Empire (claimed Roman succession), Napoleon's Empire (claimed Carolingian/Roman succession). Connected to their parent trunk node by a solid purple horizontal branch.

Lane 3 (Far-Right, teal nodes, dashed connector): Concurrent but independent empires. Civilizations that rose and fell in parallel with a trunk empire, on different continents, with no direct succession claim. Examples: Han Dynasty (contemporary with Rome), Viking Age (contemporary with Byzantine), Japanese Imperial Age (contemporary with the British Empire). Connected to the trunk at their chronological starting point by a dashed teal horizontal branch.

Node Content on the Hub

Each empire node on the hub displays: Empire name (Cinzel, 13px, font-weight 600), date range (Cormorant Garamond, 11px, italic), relationship type (for fork/concurrent nodes: "fork · dates" or "concurrent · dates"), and — once the empire file is built — a clickable link to that file. Unbuilt empire files show the node as slightly dimmed (opacity: 0.5) with no link, and the text "(forthcoming)" in muted gold.

Hub Header

The hub header reads: ornament line → H1 "EMPIRES OF HISTORY / IN FILM & SERIES" → subtitle "A complete cinematic atlas, from earliest kingdoms to modern empires" → date range "1550 BC — 1945 AD" (or appropriate range for the included empires).

Hub Legend

A legend at the bottom of the hub explains the three node types and two connector types. It uses the same format as the legend in individual empire files (inline flex, small badges).

Hub Does NOT Contain Phase Content

The hub contains NO film listings, NO phase descriptions, NO character spotlights. The hub is purely a navigational map. All detailed content lives in the individual empire files. The hub's only job is to show the relationships between empires and link to each empire's file.

VII

Individual Empire Timeline File Structure

Every empire file follows this exact structure from top to bottom. Do not reorder or skip any section.

  1. DOCTYPE, meta, title, font import — Standard HTML5 boilerplate. Title format: "[Empire Name] — The Complete Cinematic History".
  2. <style> block — Complete CSS, entirely self-contained. Base :root variables, then empire accent override, then all component styles. See Section XII for the exact boilerplate.
  3. Header — Ornament line, back-link to hub, H1 title, subtitle, header-line with date range.
  4. Tree container (div.tree) — Contains the trunk line (div.trunk) and all phase nodes.
  5. Phase nodes — Alternating left-right. Odd phases go left, even phases go right. Each phase contains: phase number, date, title, description, film list, optional spotlight, optional parallel label. See Section VIII for exact anatomy.
  6. Era dividers (optional) — Between major historical periods (e.g., "Kingdom → Republic → Empire" transitions), a centered horizontal divider with a label can be inserted. This is a decorative separator, not a phase node. Use sparingly — maximum 3–4 per file.
  7. End node (div.end-node) — Diamond shape in accent color, FINIS label in Latin, final year in large Cinzel 900. The Latin phrase follows the format: "FINIS [EMPIRE IN GENITIVE LATIN]". For empires where a Latin phrase is inappropriate (e.g., Mongol, Japanese), use "THE [EMPIRE NAME] FALLS" in Cinzel caps.
  8. Legend — The five badge types plus the ⟡ parallel/optional note. Always centered, always at the bottom.

The Alternating Layout — The Single Most Important Rule

Odd-numbered phases (Phase I, III, V…) place their content block on the LEFT side of the trunk. The flex-direction for odd phases is row. Even-numbered phases (Phase II, IV, VI…) place their content block on the RIGHT side. The flex-direction for even phases is row-reverse. This is enforced by the CSS selectors .phase:nth-child(odd) and .phase:nth-child(even). The trunk-node dot is always centered at 50% regardless of which side the content is on.

Critical: When odd phases have text-align: right and even phases have text-align: left, the film item list alignment must match. Odd phases' .films use align-items: flex-end. Even phases use align-items: flex-start. This ensures film cards align to the trunk side, not the outer margin.

A phase node is the core repeating unit of every empire file. Here is a visual breakdown of every element within one phase, in order:

Caesar vs Pompey · Battle of Pharsalus · Cleopatra in Alexandria · Ides of March · 23 stab wounds
SERIES Rome — Season 1, Eps. 5–12 (2005) FILM Julius Caesar (1953) — Marlon Brando FILM Cleopatra (1963) ⟡ parallel

The Seven Elements of a Phase

1. Phase Number (div.phase-num)

Format: "Phase I", "Phase II" etc. using Roman numerals. Cinzel, 10px, --accent-light color, letter-spacing 3px, uppercase. This is where the empire accent color appears most visibly.

2. Phase Date (div.phase-date)

The historical date range in gold. Format options: "753 BC", "509 – 27 BC", "27 BC – 14 AD", "1299 AD". Always use the format "[start] – [end]" for ranges. Never use "CE" or "BCE" — always "BC" and "AD". Cinzel, 11px, --gold.

3. Phase Title (div.phase-title)

A short, evocative name for the historical period. 3–7 words. Cinzel, 600 weight. Should be memorable and specific — not "Roman Expansion" but "Rome Becomes a Superpower". These titles are how users navigate and remember the timeline.

4. Phase Description (div.phase-desc)

A dense, dot-separated summary of the key events, people, and themes of this period. Format: "Person · event · outcome · context". Maximum 2 lines. Cormorant Garamond, 12.5px, italic, --text-dim color. This is the historical briefing that tells the reader WHY this period matters before they watch anything.

5. Film List (div.films)

One div.film-item per entry. Each film item contains: a badge (FILM/SERIES/MINI/DOC/DRAMA) followed by the title, year, and key cast note. Optional: a ⟡ symbol indicating a parallel/optional watch. Maximum ~8 items per phase (if more, split the phase). Always list in recommended watch order, not release year order. Items that are optional are given the class type-optional (reduced opacity).

6. Parallel Label (div.parallel-label) — Optional

Lines beginning with ⟡ that give watch-order instructions, parallel viewing notes, or accuracy warnings. Cinzel, 9px, --gold, opacity 0.65. Each line is a separate instruction. Never more than 5 lines. Examples: "⟡ Watch X before Y — it covers the earlier events" or "⟡ Watch X and Y simultaneously — they cover the same battle from different sides".

7. Character Spotlight (div.spotlight) — Optional

A box with a colored accent border (right side for left-aligned phases, left side for right-aligned phases) that spotlights one major character from this phase. Contains: spotlight label with an emoji prefix and character name, a 2–4 sentence explanation of why this character matters and which performance is best, and optionally a sub-list of 2–3 specific film items showing the best portrayals. Used for historically consequential figures who appear across multiple films or whose portrayal varies dramatically.

Spotlight Rule: Not every phase needs a spotlight. Spotlights are reserved for figures of exceptional historical importance where the choice of which film to watch first genuinely matters. Every empire file should have roughly 3–6 spotlights total — one for the founder, one for the empire's peak figure, one for the fall figure. Do not add a spotlight for minor characters.

Film Item Content Format

Every film item entry follows this exact content format inside the div.film-item:

IX

Research Methodology — How to Find & Verify Media

This is the most critical section of the entire document. The quality of the project depends entirely on the accuracy and completeness of the media listed. Follow this exact research process for every empire.

Step 1 — Define the Historical Skeleton

Before searching for any media, write out the complete list of historical phases for the empire (as described in Section VIII). Know the key dates, key figures, and key events. This skeleton is built from historical knowledge, not from media searches. The phases are determined by history; the media is then mapped onto those phases. Never build phases around the media you happen to find.

Step 2 — Primary Media Search Queries

Run web searches for each of the following query types. All searches should specify the empire name explicitly:

Query TypeExample QueryPurpose
Overview query "best movies TV series [empire] history complete list" Gets the major known titles quickly
Period-specific query "films about [specific figure or event] [empire]" Finds media for specific phases with thin coverage
Non-English media query "[native language] TV series [empire name in native language]" Finds Turkish, Chinese, Indian, Japanese productions
Documentary query "BBC documentary [empire] history" / "Netflix documentary [empire]" Fills gaps where drama coverage is thin
Accuracy check query "most historically accurate [empire] films" Confirms which entries are defensible recommendations
Gap-filling query "films set in [specific century/reign period]" Addresses phases with no obvious media match

Step 3 — Verification Rules

Before including any media item, verify all three of the following:

  1. The media actually exists. Confirm title, year, and that it was actually produced. Do not include announced-but-not-produced projects or incorrectly remembered titles.
  2. The media actually covers the claimed period. A film listed under "Phase V — 73 BC" must genuinely be set in that era. If a film is set across multiple phases, list it only in the phase where it begins, with a note that it spans forward.
  3. The media is findable by a general audience. It must be available on a major streaming platform, purchasable digitally, or available on DVD. Do not list obscure films that cannot be accessed. Italian peplum films are acceptable as optional items since many are on YouTube, but must be flagged as such.

Step 4 — Handling Media Gaps

Some historical phases have no drama or film coverage. This is expected and must be handled honestly:

  • First, check if there is a documentary that covers the period. BBC, National Geographic, and History Channel have broad historical coverage.
  • If no documentary exists, check for a relevant episode of a documentary series (e.g., Mary Beard's Rome, Civilisations, etc.).
  • If still nothing, mark the phase with the note "⟡ No major drama covers this era — documentary bridge recommended" and suggest the best available background resource.
  • Never invent or fabricate media entries. A gap is better than a false entry.

Step 5 — Non-Western Media Rules

For empires outside the Western European tradition, the research must include native-language productions. The Ottoman, Mongol, Mughal, Han, Japanese, and Islamic files must each contain a meaningful proportion of media produced in the empire's home culture:

  • Ottoman: Turkish series (Diriliş: Ertuğrul, Muhteşem Yüzyıl/Magnificent Century, Rise of Empires: Ottoman)
  • Mongol: Mongolian film Genghis Khan (2012), Chinese co-productions, Sergei Bodrov's Mongol (2007)
  • Mughal: Bollywood productions (Mughal-E-Azam, Jodhaa Akbar, Bajirao Mastani)
  • Han/Chinese: Chinese historical dramas (Hero, House of Flying Daggers era, Three Kingdoms series)
  • Japanese: Akira Kurosawa's complete filmography plus modern NHK Taiga dramas

Step 6 — Watch Order Logic

Within each phase, items are listed in recommended watch order, not chronological release order. The rules for determining watch order are:

  1. Any series that begins before the phase's start date but overlaps into it goes first.
  2. The primary narrative item (usually the most accurate or most comprehensive) goes first.
  3. Parallel items (items covering the same events from a different perspective) are listed after the primary, with a ⟡ note.
  4. Optional items (lower accuracy, or covering a minor sub-event) go last and use the type-optional class.
  5. Documentaries always go after dramas within the same phase, unless they serve as an essential historical briefing that should be watched before the drama to understand context.

The 18 Empires — Individual Build Briefs

Brief notes for each empire file. These are the key facts the builder needs before beginning research, including the critical media anchors (the 1–3 most important media items that form the backbone of each file) and the known coverage gaps.

Egypt (egypt.html)

Dates: New Kingdom ~1550 BC – Cleopatra's death 30 BC (after which Egypt becomes a Roman province). Accent: Nile turquoise (#1a6b6b). Key phases: New Kingdom glory (Ramesses II), Third Intermediate Period decline, Ptolemaic Greek dynasty, Cleopatra. Media anchors: The Ten Commandments (1956), Pharaoh (1966, Polish), Nefertiti: Daughter of the Sun (1994). Gap: The Amarna period (Akhenaten/Nefertiti) has minimal dramatization — use documentaries. Cross-reference Rome file: the Cleopatra phases overlap and files should direct viewers to each other.

Persia (persia.html)

Dates: Achaemenid ~550–330 BC. Accent: Royal amethyst (#5a2080). Key phases: Cyrus the Great's rise, Darius and Xerxes' Greek Wars, Alexander's conquest. Media anchors: 300 (2007), 300: Rise of an Empire (2014), One Night with the King (2006 — Esther/Xerxes). Note: Persian films are told primarily through the enemies' eyes (Greek films). Must include Persian-sympathetic context via documentaries (BBC's Persian Empire series). The empire's foundation by Cyrus has almost no screen coverage — gap to flag.

Macedonian / Alexander (macedon.html)

Dates: 336–323 BC (Alexander's reign). Can include Philip II buildup from ~359 BC. Accent: Macedonian blue (#2a3d8b). Key phases: Philip II unifying Greece, Alexander's campaigns (Persia, Egypt, India), Alexander's death and the Wars of the Diadochi. Media anchors: Alexander (2004, Oliver Stone — use Director's Cut), Alexander the Great (1956 — Richard Burton). Note: This is a short file — 4–6 phases maximum. Alexander's life IS the empire. Diadochi wars that follow are briefly covered in a final phase before transitioning out.

These are culturally very different periods and the media reflects this completely.

XI

Quality Rules & Accuracy Standards

The 8 Unbreakable Rules
  • Never invent media. Every film, series, or documentary listed must actually exist and be verifiable. If uncertain, search before including.
  • Never list a film under a period it does not cover. Historical setting must match the phase date. Verify before listing.
  • Always include the year. Every media entry must include the production year in parentheses. This prevents confusion between remakes (e.g., Spartacus 1960 vs the Starz series).
  • Mark parallels explicitly. Any item that covers the same events as another item in the same phase must be marked ⟡ parallel in the film item text and explained in the parallel-label below.
  • Always give a watch-order rationale. For each phase with more than 2 items, the parallel-label must explain WHY items are in the listed order. Users need to know which to watch first and why.
  • Never recommend an inaccessible film as primary. If the best film for a period is extremely rare, list it as optional and recommend a more accessible alternative as primary.
  • Be honest about accuracy. If a film is well-known but historically inaccurate, say so in the parallel-label. Example: "⟡ Gladiator (2000) takes creative liberty with the timeline but captures the spirit correctly."
  • Include non-Western perspectives wherever they exist. For every empire that is sometimes portrayed as "the enemy" in Western films (Persia in 300, Mongols in countless films), find media that shows their own perspective and include it.

What Counts as "Adequate Media Coverage"

An empire qualifies for inclusion in this project only if it has at least 8 distinct media items across its timeline. These 8 items can include documentaries and non-English productions. Empires with fewer than 8 items are too thinly covered to build a satisfying timeline and should be noted in the hub as "insufficient coverage" rather than given a dedicated file.

Handling Controversial or Explicit Content

Some historically significant films contain explicit violence or adult content (e.g., Caligula 1979, certain gladiatorial films). These must be included because they are part of the honest cinematic record, but must be flagged with a ⚠ warning symbol inline and noted as "explicit content" in the parallel-label. The warning symbol appears directly after the film title in the film-item text.
